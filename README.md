# Lavanya Pulijala — Portfolio

Personal portfolio site for Lavanya Pulijala, art director and creative director.

## Structure

- `index.html` — homepage (hero, work rail, about, footer)
- `work.html` — "All Series" full work listing page
- `style.css` — shared styles for all pages
- `script.js` — shared behavior (hero letter animation, category dropdown)

## Local preview

Open `index.html` directly in a browser. All pages reference `style.css` and
`script.js` via relative paths, so keep all files in the same folder.
